# 学生成绩管理系统

这是一个使用 C++ 编写的控制台学生成绩管理系统，主要用于完成程序设计课程设计任务。系统以班级学生成绩数据为基础，实现了学生信息管理、成绩查询、成绩统计、成绩排名、缺考补录和文件读写等功能。

## 项目功能

- 学生信息查询  
  - 按学号查询
  - 按姓名模糊查询
  - 按成绩条件查询优秀或不及格学生

- 成绩显示与排名  
  - 支持按第 1～6 次考试成绩进行排名
  - 支持全年级排名和班级排名显示
  - 支持同分同排名

- 成绩统计  
  - 统计各次考试平均分
  - 统计各次考试最高分、最低分
  - 统计不及格人数
  - 统计优秀人数
  - 输出缺考学生名单

- 学生信息维护  
  - 添加学生信息
  - 删除学生信息
  - 修改学生姓名、学号和成绩
  - 补录缺考成绩

- 文件读写  
  - 从 `class1.txt`、`class2.txt` 中读取学生数据
  - 将修改后的数据保存回文本文件
  - 支持程序退出前保存数据

## 技术要点

本项目主要使用了 C++ 基础语法和 STL 容器，包括：

- `class` 定义学生数据结构
- `vector` 存储班级学生信息
- `fstream` 实现文件读写
- `string` 处理姓名和学号
- `algorithm` 实现排序和查找
- 控制台菜单实现交互式操作
